# 부경대 공지알리미 — 게시판 목록

부경대 공지알리미 앱이 읽어가는 **게시판 목록 파일 한 개**만 두는 저장소입니다.
앱 소스는 여기 없습니다.

## 왜 따로 있나

학교가 학과 홈페이지 주소를 바꾸면 그 게시판이 앱에서 안 열립니다. 예전에는 APK를 새로
만들어 배포하고 사용자가 직접 다시 설치해야 고쳐졌는데, 스토어가 아니라 링크로 받는
앱이라 고장난 채로 몇 주씩 남았습니다.

이제 여기 `boards.json`만 고치면 이미 설치된 앱도 하루 안에 새 주소를 받아갑니다.

## 서버가 아닙니다

앱은 이 파일을 받아가기만 합니다. 앱이 보내는 것은 "이 파일 주세요"가 전부이고,
휴대폰이나 사용자에 대한 정보는 아무것도 실리지 않습니다.

파일을 못 받거나 내용이 검사에 걸리면 앱은 APK에 들어 있는 기본 목록을 그대로 씁니다.
그래서 이 저장소가 사라져도 앱은 그대로 동작합니다.

## 형식

```json
{
  "version": 1,
  "boards": [
    {
      "id": "국어국문학과",
      "college": "인문사회과학대학",
      "name": "국어국문학과",
      "url": "https://kukmun.pknu.ac.kr/korean/5186"
    }
  ]
}
```

| 항목 | 설명 |
| --- | --- |
| `id` | 게시판 고유 이름. **바꾸면 그 게시판에 대한 사용자의 선택·읽음·북마크가 끊깁니다.** 주소만 바뀐 경우 `id`는 그대로 두세요. |
| `college` | 단과대학. 관심 게시판 화면에서 묶는 기준입니다. |
| `name` | 화면에 보이는 이름 |
| `url` | 공지 목록 페이지 주소 |
| `hasDeptOffice` | 생략하면 `true`. 학과 연락처 목록에 넣지 않을 게시판만 `false`로 둡니다. |

## 고칠 때 지킬 것

앱은 아래 중 **하나라도** 걸리면 이 파일을 통째로 버리고 내장 목록으로 돌아갑니다.
목록이 반쯤만 맞는 상태가 가장 나쁘기 때문에, 일부만 받아들이지 않습니다.

- 게시판이 50개 미만
- `id` · `college` · `name` 중 빈 값이 있음
- `url`이 `http://` 또는 `https://`로 시작하지 않음
- 같은 `id`가 두 번 나옴

바뀐 내용은 **앱을 다시 켤 때** 반영됩니다. 확인은 하루 한 번만 합니다.

## 만드는 법

이 파일은 손으로 고치지 말고 앱 소스의 `Board.kt`에서 뽑습니다. 그래야 APK에 들어가는
기본 목록과 어긋나지 않습니다.

```
python tools/make_boards_json.py <이 저장소>/boards.json
```
